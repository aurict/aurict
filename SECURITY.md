# Security Policy

## Reporting a vulnerability

Please report security issues privately. Do not open a public issue or pull request.

- Preferred: [GitHub private vulnerability reporting](https://github.com/aurict/aurict/security/advisories/new)
- Email: security@aurict.com

Include what you found, the affected component (CLI, desktop, mobile, a website or the backend at `api.aurict.com`), steps to reproduce, and the impact you expect. We aim to acknowledge reports within 3 working days and to agree on a disclosure date with you once a fix is ready.

## Scope

In scope: code in this repository and the services it runs (`aurict.com`, `mobile.aurict.com`, `decision.aurict.com`, `quaera.aurict.com`, `api.aurict.com`).

Out of scope: denial of service through traffic volume, social engineering, findings that need a compromised device or account, and reports produced only by automated scanners without a working impact.

## Supported versions

Only the latest release of the CLI, desktop and mobile apps receives security fixes. The hosted services are deployed from `main`.

Please do not access or modify data that is not yours while testing, and stop and report as soon as you see someone else's data.
